# Postman Parallel Test Runner

This project contains automated API tests using Postman collections that can be run in parallel using Newman. The tests cover merchant and partner mutations and queries for the GraphQL API.

## Prerequisites

Before running the tests, make sure you have:

- Node.js (v14 or higher) installed
- NPM (Node Package Manager) installed
- Access to the API endpoints being tested
- Required API keys and credentials
